# Jogo da Velha em Java

Projeto desenvolvido em Java como parte de um trabalho acadêmico,
utilizando JOptionPane para interação com o usuário.

## Funcionalidades
- Escolha do símbolo (X ou O)
- Tabuleiro 3x3
- Alternância entre dois jogadores
- Validação de jogadas
- Verificação de vitória
- Verificação de empate

## Tecnologias
- Java
- Swing (JOptionPane)

## Como executar
1. Clone o repositório
2. Abra o projeto em uma IDE Java (Eclipse, IntelliJ ou VS Code)
3. Execute a classe `JogoDaVelha`

## Aprendizados
- Lógica de programação
- Estruturas condicionais
- Laços de repetição
- Manipulação de arrays bidimensionais
- Organização de código
